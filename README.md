# CRM AI Assistant

### AI assisted customer conversations, summaries, and reply drafts

## The problem

Customer facing teams manage many leads and conversations across channels. They need to understand context quickly, respond consistently, and follow customer preferences without losing human judgment.

## Product goal

Help users summarize customer conversations, draft replies, prioritize leads, and create workflows while keeping the user in control of every customer facing action.

## My role

As a Senior AI Product Analyst, I worked across CRM, marketing automation, customer engagement, and AI assisted workflows to:

- Define requirements for leads, contacts, conversations, pipelines, appointments, and automations
- Map lead to customer journeys and identify workflow gaps
- Create user stories, acceptance criteria, business rules, and backlog priorities
- Define expected AI output, human review steps, and failure handling
- Validate API behavior and data issues using Postman and SQL
- Measure adoption, edit rates, conversion funnels, workflow performance, and AI acceptance

## Core capabilities

- Conversation summaries
- AI generated reply drafts
- Lead priority suggestions
- Assisted workflow creation
- Contact matching and duplicate handling
- Appointment and pipeline workflows
- Automation triggers, retries, permissions, and execution history

## Product safeguards

| Scenario | Expected behavior |
| --- | --- |
| Pricing information is unavailable | Ask the user to verify pricing instead of inventing it |
| Customer requests no more messages | Suppress promotional follow up and respect the opt out |
| AI draft is generated | User can edit, discard, or send it |
| Contact data is unclear | Avoid merging records without approved matching rules |
| Context is insufficient | Ask for more information or provide no draft |

## Success measures

| Metric | Why it matters |
| --- | --- |
| Draft acceptance rate | Shows whether users find AI replies useful |
| Draft edit rate | Identifies output quality gaps |
| Time to reply | Measures workflow efficiency |
| Lead to appointment conversion | Measures business impact |
| Opt out failure count | Protects customer trust and compliance |
